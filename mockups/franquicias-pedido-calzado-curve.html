Franquicias › Pedido de calzado

Primero el cliente (impacta en Dragonfish), después filtros de temporada / material / grupo / familia, y se arma la nota de pedido de venta.

Cómo funciona

  1. 1 · Cliente obligatorio: apenas entrás hay que seleccionar el cliente (ID Cliente de MITO). Hasta que no lo elegís, la tabla y los filtros quedan bloqueados. Ese ID Cliente es el que después impacta en Dragonfish al grabar la nota de pedido. 1.990 clientes reales
  2. 2 · Filtros multi-selección de Temporada (Verano / Continuo / Invierno / Atemporal), Material, Grupo y Familia. Podés tildar varios en cada uno; se combinan entre sí y filtran la tabla al instante.
  3. 3 · Curva de talles: dos solapas (zapatillas talle simple / chanclas y slippers talle doble). Cada celda muestra arriba el stock de MITO del talle (verde/ámbar/gris) y abajo el input para cargar los pares.
  4. 4 · Nota de pedido: con lo cargado se genera la nota de pedido de venta del cliente elegido. Excel / PDF / WhatsApp comparativo.

📇 Envío por WhatsApp Cloud API

El servidor manda el texto con WHATSAPP_TOKEN + WHATSAPP_PHONE_ID. Si todavía no están cargados, el envío igual queda registrado en el historial con el motivo ("WhatsApp no configurado") para que se vea qué faltó.

🔀 Cómo se dispara

  • A mano: botón “Enviar ahora” (permiso sistemas.informes.edit).
  • Automático: Vercel Cron revisa los diarios y manda los que ya pasaron su hora.
  • Respaldo: al abrir esta pantalla también se procesan los vencidos.
  • No se repite el mismo día: la base “reclama” cada envío (atómico).

📦 Fuentes del cuerpo

  • Vista SQL Server: cualquier vista habilitada en Datos SQL, con filtro y columnas a elección.
  • Datos de la app: Recepción INDO, Armados de pedidos, Pedidos de compra.
  • Texto libre: avisos con variables {fecha}, {hora}, {dia}.

🔐 Permisos y datos

  • sistemas.informes.view / create / edit / delete.
  • Tablas public.informes y public.informes_envios (historial).
  • El historial sólo lo escribe el servidor (service role).
